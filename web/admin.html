Players

Players are jersey colour + number only. Every player gets a primary and a secondary jersey colour at registration; the number is the same on both. A player's code is built from the primary colour (White 14 = W-14). Within one jersey set, use colours with different first letters. Pick a colour from the list or choose Other… to add a new one. Never paste a roster with names.

Position and secondary colour can be changed in the table (they save immediately). Delete only works for players with no scores yet; use Release once scoring has started. Tick AA for players still being considered for the AA team: evaluators see the badge on that player's card.

Teams

Teams are groups of players you reuse across scrimmages and games. Give each team a colour: every player on it wears that colour, whatever their own default jersey (White 433 on a Red team shows as R-433). Make as many teams as you need (a player can be on more than one), then on each scrimmage session pick which teams are on the ice; the colour is filled in from the team and can be changed for that session only. Players not on a playing team are not dressed for that session: evaluators don't see them and cannot score them.

Sessions (ice times)

Label, date and type can be changed right in the table; they save as soon as you leave the field. Each session says which of the two jersey colours players wear. Skills sessions normally use the primary colour; scrimmages often use the secondary one. Evaluators see the colour worn that session; scores always stay with the player.

Attendance & jerseys

For each ice time: untick anyone who is not on the ice, and set the jersey colour each player is wearing. Absent players disappear from the evaluators' screens for that session only and cannot be scored for it. Colours set here are what evaluators see for that session; the number never changes.

Evaluators

Evaluators sign in with their email and a one-time code; there is no password to send. Use a label like "Evaluator 3" — the label is what you see in the rankings, so keep it neutral if you prefer blind evaluators. A login only works on a tryout it has been added to; use Disable to cut someone off without deleting them or their scores.

Close the tryout

Closing stops all scoring. Evaluators can still open the app and see their own scores, read-only. This cannot be undone from the app.
